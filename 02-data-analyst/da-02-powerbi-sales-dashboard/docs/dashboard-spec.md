# Dashboard specification

Audience: the sales director and CFO. The question they need answered in 30 seconds: **"Is our growth profitable, and if not, where does the margin go?"** Every chart title states the finding; numbers come from [expected-values.md](expected-values.md) and are verified in [dax-validation.md](dax-validation.md).

The pages are generated by [`tools/build_pbip.py`](../tools/build_pbip.py); this file describes what it builds. Canvas 1280 × 720.

## Page 1 · Executive overview

```text
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ [Fiscal Year ▾]  [Channel ▾]                                                         │
├──────────────┬──────────────┬──────────────┬──────────────┬──────────────────────────┤
│ Total Sales  │ Gross Profit │ Gross Margin │ Orders       │ Avg Order Value          │
├──────────────┴──────────────┴──────────────┼──────────────┴──────────────────────────┤
│ Line: Total Sales vs Total Sales PY        │ Table: fiscal year, sales, YoY %,        │
│ by month                                   │ margin, margin change, orders            │
├────────────────────────────────────────────┼─────────────────────────────────────────┤
│ Clustered bar: Gross Margin % by Channel,  │ Bar: Gross Margin % by Country,          │
│ one bar per fiscal year                    │ tooltip Reseller Share %                 │
└────────────────────────────────────────────┴─────────────────────────────────────────┘
```

| Visual | Fields | Title |
| --- | --- | --- |
| Slicers (2) | `Date[Fiscal Year]`, `SalesOrder[Channel]` (dropdown) | — |
| Cards (5) | `Total Sales`, `Gross Profit`, `Gross Margin %`, `Orders`, `Avg Order Value` | the measure name |
| Line chart | X `Date[Month]` (sorted by `MonthKey`); Y `Total Sales`, `Total Sales PY` | Monthly sales vs prior year: FY2020 grew 52% |
| Table | `Fiscal Year`, `Total Sales`, `Sales YoY %`, `Gross Margin %`, `Margin Change pp`, `Orders` | Fiscal years at a glance |
| Clustered bar | Category `Channel`; series `Fiscal Year`; value `Gross Margin %`; data labels | Resellers bring 73% of sales at a margin near zero; Internet earns 41% |
| Bar | Category `SalesTerritory[Country]`; value `Gross Margin %` (sorted); tooltip `Reseller Share %` | Country margin follows channel mix: Australia 34% (15% reseller), Canada 6% (88%) |

## Page 2 · Where the margin goes

```text
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ [Fiscal Year ▾]  [Category ▾]                                                        │
├────────────────────────────────────────────┬─────────────────────────────────────────┤
│ Matrix: Category > Subcategory > Product   │ Bar: Gross Profit by Product,           │
│ Sales, Profit, Margin %, Sales YoY %       │ sorted (top products first)             │
├────────────────────────────────────────────┼─────────────────────────────────────────┤
│ Scatter: subcategories                     │ Card: Loss Lines                         │
│ X sales, Y margin %, size units            ├─────────────────────────────────────────┤
│                                            │ Bar: Loss Amount by reseller type       │
└────────────────────────────────────────────┴─────────────────────────────────────────┘
```

| Visual | Fields | Title |
| --- | --- | --- |
| Slicers (2) | `Date[Fiscal Year]`, `Product[Category]` | — |
| Matrix | Rows `Category` › `Subcategory` › `Product`; values `Total Sales`, `Gross Profit`, `Gross Margin %`, `Sales YoY %` | Jerseys, touring frames and caps are sold at a loss (expand to subcategory) |
| Bar | Category `Product[Product]`; value `Gross Profit`, sorted descending | Mountain-200 bikes make the most profit |
| Scatter | Details `Product[Subcategory]`; X `Total Sales`; Y `Gross Margin %`; size `Units` | Subcategories: sales vs margin (bubble size = units) |
| Card | `Loss Lines` | — |
| Bar | Category `Reseller[Business Type]`; value `Loss Amount`; data labels | Sold below cost: loss by reseller type |

## Style

- Base theme Fluent 2 (Oct 2026) as shipped with Power BI Desktop; no custom colours.
- No 3D, pie charts or gauges. Bars sorted by value. Data labels only where the exact number matters.
